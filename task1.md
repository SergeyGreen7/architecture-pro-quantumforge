# Задание 1. Исследование моделей и инфраструктуры

## 1. Сравнение LLM-моделей

| Критерий | Локальные модели Hugging Face | OpenAI API | YandexGPT |
|---|---|---|---|
| Качество | Зависит от модели; хорошие результаты у современных Qwen | Обычно высокое для сложных задач | Хорошее для русскоязычных задач |
| Скорость | Зависит от GPU, нагрузки и контекста | Зависит от API и сети | Зависит от API и сети |
| Стоимость | Сервер, электроэнергия, обслуживание | Оплата токенов | Оплата по тарифу |
| Развёртывание | Требует настройки инференса | Простое API | Простое API |
| Конфиденциальность | Возможна полностью локальная обработка | Данные обрабатывает внешний провайдер | Данные обрабатываются в облаке Yandex |
| Работа без интернета | Возможна | Нет | Нет |

**Локальные модели:** Qwen3-8B или Qwen3-14B; запуск через Ollama, vLLM или Transformers. Плюсы — контроль данных и отсутствие платы за токены. Минусы — инфраструктура и администрирование.

**OpenAI:** быстрый запуск и сильные модели без собственного GPU, но есть расходы на API и требования к допустимости передачи данных.

**YandexGPT:** удобен для русскоязычных корпоративных сценариев и интеграции с Yandex Cloud, но не является локальным решением.

**Вывод:** при строгой конфиденциальности предпочтительна локальная LLM; для разрешённых к облачной обработке данных API ускоряет пилот.

## 2. Сравнение моделей эмбеддингов

| Критерий | Sentence-Transformers (локально) | OpenAI Embeddings (облако) |
|---|---|---|
| Примеры | multilingual-e5-base, BAAI/bge-m3 | text-embedding-3-small, text-embedding-3-large |
| Индексация | Скорость зависит от CPU/GPU, возможен batch | Зависит от API, сети и лимитов |
| Качество поиска | Высокое при правильной модели и настройке | Высокое; требует проверки на корпусе |
| Стоимость | Вычислительные ресурсы | Оплата токенов |
| Русский язык | Поддерживается мультиязычными моделями | Поддерживается |
| Конфиденциальность | Данные остаются локально | Тексты отправляются в API |

**Рекомендация:** BAAI/bge-m3 для локального поиска по русскоязычным и смешанным документам. Начать с dense-эмбеддингов, затем при необходимости добавить гибридный поиск и reranking.

## 3. Сравнение ChromaDB и FAISS

| Критерий | ChromaDB | FAISS |
|---|---|---|
| Тип | Векторная БД | Библиотека поиска ближайших соседей |
| Поиск | Быстрый ANN-поиск | Очень быстрый; много вариантов индексов |
| Индексация | Удобная работа с коллекциями | Гибкая настройка, больше кода |
| Тексты и метаданные | Встроенное хранение | Нужен дополнительный слой хранения |
| Фильтрация | Встроенная по метаданным | Обычно реализуется отдельно |
| Развёртывание | Простой локальный и серверный режим | Нужна собственная обвязка |
| Стоимость лицензии | Open source | Open source |
| Владение | Инфраструктура и обслуживание | Инфраструктура и обслуживание собственной системы |

**ChromaDB** хранит эмбеддинги, фрагменты текста, идентификаторы и метаданные. Поддерживает коллекции, фильтрацию, локальное постоянное хранилище и клиент-серверный режим.

**FAISS** предоставляет Flat, IVF, HNSW, PQ и другие индексы; полезна при больших объёмах данных и необходимости тонкой оптимизации, но не заменяет хранилище документов и прав доступа.

**Вывод:** для примерно 100 000–300 000 фрагментов из 10 000 документов предпочтительна **ChromaDB** из-за меньшей сложности внедрения. FAISS стоит рассмотреть при росте до миллионов векторов и специфических требованиях к скорости.

## 4. Рекомендуемая инфраструктура

| Компонент | Конфигурация |
|---|---|
| CPU | 8–12 ядер |
| RAM | 32–64 ГБ |
| GPU | Не требуется для пилота; LLM доступна через API Yandex Cloud |
| SSD | NVMe 1–2 ТБ |
| ОС | Ubuntu Server 24.04 LTS |
| Контейнеризация | Docker |
| Backend | Python + FastAPI |
| LLM | YandexGPT через API Yandex Cloud |
| Эмбеддинги | BAAI/bge-m3 |
| Векторная БД | ChromaDB |

Для старта пилота собственный GPU-сервер не нужен: генерацию выполняет YandexGPT через API Yandex Cloud. Локальные ресурсы используются для backend, обработки документов, построения эмбеддингов и ChromaDB. Перед отправкой контекста в облачную LLM необходимо проверять права доступа и исключать документы, для которых облачная обработка не разрешена.

## 5. Четыре варианта реализации

| Вариант | Стек | Плюсы | Минусы |
|---|---|---|---|
| 1. Локальный | Qwen3-8B + BGE-M3 + ChromaDB | Контроль конфиденциальных данных | GPU, администрирование |
| 2. Облачный OpenAI | OpenAI LLM + OpenAI Embeddings + ChromaDB | Быстрый запуск | Внешняя обработка, переменные расходы |
| 3. Облачный YandexGPT | YandexGPT + BGE-M3 + ChromaDB | Русскоязычная интеграция | Облачная обработка |
| 4. Гибридный | Локальная Qwen + OpenAI для разрешённых данных + BGE-M3 + ChromaDB | Гибкость | Сложнее маршрутизация и контроль доступа |

**Допущения для бюджета:** 10 000 вопросов/месяц, в среднем 3 000 входных и 500 выходных токенов на вопрос. Это 30 млн входных и 5 млн выходных токенов ежемесячно.

**Предварительные оценки:**

- Локальный сервер: ориентировочно $2 500–5 000 первоначально, затем электричество, ремонт и администрирование.
- OpenAI: стоимость определяется актуальной ценой выбранной модели; например, при условном тарифе $0,10/млн входных и $0,50/млн выходных токенов — $5,50/месяц только за генерацию. Это иллюстрация формулы, а не подтверждённая текущая цена конкретной модели.
- YandexGPT: при условном тарифе $0,00656 за 1 000 токенов — около $229,60/месяц. Фактический тариф нужно проверить по модели, региону и типу запроса.
- Гибридный: расходы на локальную инфраструктуру плюс токены облачной части.

## 6. Вывод

**Рекомендуемый вариант для старта пилота: YandexGPT в Yandex Cloud + BAAI/bge-m3 + ChromaDB.**

Причины выбора:

1. **Быстрый запус:** YandexGPT доступен через API, поэтому для пилота не нужно закупать GPU-сервер и настраивать локальный инференс.
2. **Качество русского языка:** модель подходит для русскоязычного корпоративного сценария и интегрируется с сервисами Yandex Cloud.
3. **Низкий порог входа:** на этапе пилота расходы зависят от фактического объёма API-запросов, а не от предварительной закупки оборудования.
4. **Простота RAG-слоя:** ChromaDB хранит векторы, тексты и метаданные, а BGE-M3 поддерживает мультиязычный поиск.
5. **Возможность проверки гипотезы:** пилот позволит измерить качество, задержку и фактическую стоимость до выбора целевой архитектуры.

Пилот следует начать с YandexGPT в Yandex Cloud, чтобы быстро проверить качество и экономику RAG-сценария без закупки GPU. ChromaDB остаётся наиболее практичным векторным хранилищем для первой версии. По итогам пилота следует отдельно решить, оставаться ли на облачной LLM или переходить на локальную модель для чувствительных данных или снижения стоимости при масштабировании.
