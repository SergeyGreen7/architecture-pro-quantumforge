# Векторный индекс базы знаний QuantumForge

В этой папке находится готовый постоянный индекс ChromaDB и код, которым он
создан. Индекс построен по псевдонимизированной базе знаний из
`docs/knowledge_base` и предназначен для семантического поиска фрагментов перед
передачей контекста в LLM.

## Выбранная модель

- **Модель:** [`BAAI/bge-m3`](https://huggingface.co/BAAI/bge-m3)
- **Тип:** локальные dense-эмбеддинги через `sentence-transformers`
- **Размер вектора:** 1024 числа
- **Нормализация:** L2; сходство в ChromaDB вычисляется по cosine distance
- **Причина выбора:** это мультиязычная модель из архитектурного решения в
  `task1.md`; она подходит для русскоязычной базы и не требует отправки текста
  внешнему API.

Модель эмбеддингов не является LLM. Она используется только для преобразования
документов и запросов в векторы. YandexGPT из задания 1 на этапе индексации не
вызывается.

## Состав результата

| Артефакт | Назначение |
|---|---|
| `chroma_db/` | готовый постоянный индекс ChromaDB (`chroma.sqlite3` + HNSW-файлы) |
| `src/build_index.py` | чтение документов, чанкинг, генерация эмбеддингов и запись индекса |
| `src/search_index.py` | пример поиска и вывод источника/позиции каждого результата |
| `src/evaluate_index.py` | три воспроизводимых smoke-теста качества |
| `src/index_utils.py` | общая конфигурация модели и преобразование результатов |
| `index_manifest.json` | параметры, контрольная сумма корпуса и фактические метрики сборки |
| `test_queries.json` | запросы и найденные чанки вместе с оценками сходства |
| `pyproject.toml` | зависимости и настройки проекта для `uv` |
| `uv.lock` | зафиксированные версии всех прямых и транзитивных зависимостей |
| `.python-version` | версия Python 3.12, которую использует `uv` |
| `requirements.txt` | те же прямые зависимости для совместимости с `pip` |

## Параметры готового индекса

| Показатель | Значение |
|---|---:|
| Документов `.txt` | 137 |
| Чанков | 203 |
| Размер чанка | до 200 слов |
| Перекрытие | 30 слов |
| Средний размер | 132,48 слова |
| Медианный размер | 140 слов |
| Минимальный / максимальный размер | 25 / 200 слов |
| Размерность эмбеддингов | 1024 |
| Векторная БД | ChromaDB 1.5.9 |
| Коллекция | `quantumforge_knowledge_base` |
| Метрика | cosine distance |
| Устройство сборки | CPU |
| Генерация эмбеддингов | 39,608 с |
| Полное построение индекса | 41,508 с |

Время измерено на текущем компьютере при уже загруженных весах модели и не
включает первоначальную установку зависимостей и скачивание `BAAI/bge-m3`.

Для разбиения используется `RecursiveCharacterTextSplitter`. Короткие статьи
сохранены целиком, поэтому часть чанков меньше рекомендуемых 100 слов: это не
смешивает разные сущности только ради достижения минимального размера.

Метаданные каждого чанка содержат:

- `source`, `filename`, `title`;
- `chunk_index`, `total_chunks`;
- `start_char`, `end_char`;
- `word_start`, `word_end`, `word_count`.

Эти поля позволяют боту показать исходный файл и точное положение найденного
фрагмента при цитировании.

## Установка

Из корня проекта:

```bash
cd task3
uv sync
```

`uv sync` создаёт `.venv`, при необходимости устанавливает Python 3.12 и
устанавливает точные версии зависимостей из `uv.lock`. Если `uv` ещё не
установлен, используйте [официальную инструкцию](https://docs.astral.sh/uv/getting-started/installation/)
или на macOS выполните `brew install uv`.

Для повторной сборки индекса:

```bash
uv run python src/build_index.py --rebuild
```

По умолчанию скрипт читает `../docs/knowledge_base` и записывает индекс в
`task3/chroma_db`. При первом запуске веса модели скачиваются с Hugging Face.
Пути и устройство можно изменить параметрами:

```bash
uv run python src/build_index.py \
  --source ../docs/knowledge_base \
  --index-dir ./chroma_db \
  --device cpu \
  --batch-size 4 \
  --rebuild
```

На macOS CPU выбран безопасным значением для `auto`, так как поддержка MPS
зависит от сочетания версии macOS и PyTorch. На машине с CUDA `auto` выберет GPU.

## Поиск

```bash
uv run python src/search_index.py \
  "Как Аркон Вейр путешествует между измерениями и какое устройство использует?" \
  --top-k 3
```

Первый результат готового индекса:

```text
score=0.6300
docs/knowledge_base/Аркон Вейр.txt — Аркон Вейр,
chunk 1/2, chars 0–1297
```

Для программной обработки можно добавить `--json`.

```bash
uv run python src/evaluate_index.py
```
